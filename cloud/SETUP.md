# Google 登录与云同步配置（尚未启用）

用户尚未建立Firebase项目。本仓库默认 `UEC_FIREBASE_CONFIG=null`，登录/上传/读取按钮禁用，未创建外部项目、部署规则或实际传输学习资料。

1. 在Firebase控制台建立自己的项目，注册网页应用。无需把服务账号私钥、OAuth client secret放进网站。
2. Authentication → Sign-in method启用Google，填写支持邮箱。将实际站点域名加入Authorized domains；本地测试可添加localhost。不要假定GitHub Pages已自动获授权。
3. 创建Firestore数据库，选择合适区域；由项目管理者审阅并部署本目录firestore.rules。规则只允许本人UID读取/修改users/{uid}/state/current，其他路径默认拒绝，禁止客户端删除。不要用开放测试规则上线。
4. 将公开网页配置填到firebase-config.js：`window.UEC_FIREBASE_CONFIG={apiKey:'...',authDomain:'...',projectId:'...',appId:'...'};`。这些是客户端公开配置，安全边界依赖认证、隔离规则和项目配置；不能把隐藏apiKey当访问控制。
5. 合并/发布由用户决定。本轮不部署网站、不部署Firebase规则。配置后应先在隔离测试账户验证Google弹窗、授权域名、UID隔离、双设备冲突、网络断开、账户退出以及真实备份恢复。

## 已实现的同步策略

登录不自动上传、不自动替换。读取只显示远端快照预览。上传用Firestore事务比较版本：没有读过已存在的云版本、或读取后另一设备更新，都会拒绝覆盖，要求重新读取和核对。

恢复云端快照是明确的“替换本机”操作；先写uec27-cloud-rollback本机回退副本，若空间不足则中止替换。完整本地导出仍可用。上传完整JSON上限700KB，不会为了通过限制而静默剔除白板或旧记录。单快照方案不适用于大量图片草稿，后续可按文档分片与对象存储扩展，但本轮没有假称实现无限容量。

退出后本机资料仍保留；共享设备需自行处理本机备份和资料。没有服务端AI评分、监考或多用户实时协作。

当前仅验证禁用状态、快照编解码/大小/基本结构、SDK静态构建及事务冲突逻辑。未配置真实项目，未进行真实Google OAuth、Firestore规则模拟器或跨设备端到端验证；规则文件存在不等于已经生效。不得把这一项标为真实云同步已开通。
