## 在应用里使用

「考试资料」工作区依次显示考试资料、考试日历、课本资料、历届考试资料。

- 课本资料接受 ZIP、PDF、JPEG、PNG、WebP 和 AVIF。导入时选择科目和可选册别，照片按原路径的数字顺序翻页。ZIP 可直接在应用导入，此过程使用设备上的文件。单条 ZIP 文件条目最大 512 MiB，可用空间由浏览器储存配额决定。
- 历届考试资料内建 47 份原卷目录，来自此前提供的五类高数考试。可按类别、年份和文件名查找，来源面板展示文件指纹。直接导入以前提供的五类原卷 ZIP、三个整合资料 ZIP 或 PDF，目录按 SHA-256 匹配。题目热力图的引用能跳到同一来源并在阅读时定位对应 PDF 页。
- 原文件保存在当前浏览器的 IndexedDB。可以在应用内打开、下载或移除本机副本。更换浏览器、换设备或清除网站数据后需再次导入。学习进度备份和云同步仍使用原有储存方式。公开 GitHub 中提交界面和原卷目录，不提交课本扫描和考试 PDF 本体。
- 全站搜索和资料筛选可用 Fuse.js 模糊匹配。编号维持精确查找，支持全角数字。Sonner 提供可关闭通知，Motion 的小包用于同组标签切换并遵循减少动效偏好。既有界面元素足以完成本轮，未引入 Magic UI。

## 实际验证

- Chromium 实际导入 47 份既有原卷，通过 SHA-256 一一匹配，核对指定页的 Blob 字节长度和刷新持久性。两张合成照片用于测试导入、数字页序、翻页和持久化。此次未使用四份不可读取的课本 ZIP。
- 检查 320、390、1440 像素宽的四个考试工作区页面，以及深色、减少动效、Sonner、中文错字搜索和全角小节编号。资料流程无页面错误或本地资源 404。
- 76 个导航与视窗组合，学习计划、旧限时练习、备用储存失败提示、旧备份与无效导入回归通过。
- batch05 的 2550 项内容断言（含165项独立样本）和 batch06 的7431项结构断言通过。另重跑80项常规计算、156项数学、210项科学、82项补充计算与100条公式结构检查。计算测试仅覆盖列出的算例，不能替代逐页内容审查。
- 较早的 batch02 审计和 batch04 测试在未修改的 `main` 上复现失败。前者要求后续新增小节恰等于当时批次清单，后者要求 `data/subjects.js` 等文件等于旧提交。将此记录为历史基线限制，本轮逐字节确认课程目录和教学正文未变化。

构建本地资源使用 `npm run build:source-tools`。资料测试在仓库根目录运行 `node tests/source-library.cjs`，本地服务默认端口 8052。将 `UEC_PAPER_ZIP` 指向含有全部 47 份原卷的本机存档可同时重跑完整原卷导入检查。这个测试不向第三方发送原文件。
