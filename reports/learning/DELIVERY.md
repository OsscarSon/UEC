# 前置诊断、限时练习与自适应计划

本轮基于已合并的 Dashboard 主线提交，保留原116章、180个已有笔记小节和两个高数科目的独立记录。没有新增教材章节、改写教学正文、生成图片、合并PR或部署网站。

## 实际交付

| 功能 | 已实现 | 边界 |
| --- | --- | --- |
| 前置知识诊断 | 13个课程目标、9个基础节点、18道原创诊断题；逐节点反馈、定向桥接卡、真实小节链接、复测入口；目标章节与首页可进入 | 是部分人工编排依赖链，不是116章的完整知识图谱。两题抽样通过不自动登记整章掌握 |
| 限时模拟练习 | 按五科、真实章号、教学分层、题数和时长随机组卷；逐题答案与用时持久化；刷新恢复、到时交卷；解析、自评检查点、失分原因、练习历史和本科错题本 | 复用已有原创练习，不是历届统考卷或官方评量规格；四点量表为教学自评，未实现教师/AI自动阅卷 |
| 自适应计划 | 综合前置诊断、近期自评失分、薄弱小节、到期复习、考试日期和个人课表；显示每项理由；按剩余时间安排，最多4项，只顺延1项旧任务 | 规则排序，不是预测模型；放学和学习结束时间由用户填写，默认值不是学校官方时间；未完成任务保留待安排 |
| Google云同步接入 | 本地构建的Firebase Auth/Firestore客户端；本人UID快照路径；主动读取/上传/恢复；版本事务防覆盖；恢复前本机回退备份；700KB完整快照上限 | **用户尚未设置Firebase，因此真实登录与云同步未启用**。未创建项目、部署规则或上传实际学习资料；未进行真实OAuth、规则模拟器或双设备端到端验证 |

高数I/II的练习、失分复盘和错题均使用科目命名空间；教学文本继续共用，不复制或重新迁移本轮学习记录。

## 诊断覆盖与来源

目标课程：物理第7、8、24章；化学第4、29、35章；生物第13章；高数I及II各第2、4、5章。基础节点包括运动、力、磁场、磁通量、物质的量、化学键、染色体、代数和定义域。

具体题干、答案、解释、桥接文本、真实小节链接和OpenStax原理参考URL位于 [data/prerequisites.js](../../data/prerequisites.js)。目标章身份以原课程数据为准；桥接卡不是课本新小节，没有真实小节依据的磁场与磁通量卡不编造编号。它们标记为 `instructional_sample_pending_teacher_review`，未声称已获教师、学校或董总全面审定。

考试日期优先使用用户个人设置，其次取用户日历中已填的统考日期；留空不制造日期。分层由既有练习位置映射，不声称是官方难度。未新增出题频率、学校范围、官方分值或评分细则。
