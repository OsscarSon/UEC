**当前状态：设计草稿，尚未完成逐项科学内容审核。** 尤其须检查公式方向、箭头、数值条件、术语、图中标注与细胞结构。不能把这批图自动标为 approved，也不可仅因外观美观便上线。

给 Codex 的使用规则：
1. 与 PR #1 的现有章节编号比对；严禁自行更改章节结构。
2. 图片原样保留或放置在独立目录并在开发预览中接入；正式发布前逐张核验。
3. 图示如有科学错误，应标记问题并反馈重绘；不要擅自改写错误解释使其看似正确。
4. 保留原 SVG 不覆盖；仅在明确对应且通过核验时替换。
5. 本批仅6张，不代表整个站点插图已齐全。
