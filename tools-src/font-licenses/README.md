# Font notices

All original embedded copyright, license and reserved-font-name metadata remains in the shipped font binaries. FONT_METADATA.json reproduces those embedded records for the exact shipped files. SIL-OFL-1.1.txt contains the complete SIL OFL terms, as published at https://github.com/google/fonts/blob/main/ofl/assistant/OFL.txt ; the Assistant copyright header applies to that family, while other family copyrights are listed in FONT_METADATA.json. KaTeX fonts additionally carry OFL notices in their metadata; upstream font-source MIT notice is retained from https://github.com/KaTeX/katex-fonts/blob/master/LICENSE .

The complete upstream v0.18.1 font-source notice blocks for ComicShanns, Excalifont and Xiaolai are retained in the corresponding UPSTREAM-NOTICE files, including cases where the subset binary omits a separate license name record.
The bundled legacy Liberation Sans identifies Ascender 2007; the GPL/font-exception license and COPYING from the upstream liberation-1.7-fonts repository are retained, with exact source URLs and Git blob SHAs in LIBERATION_SOURCE.json. This family is not relabeled MIT/OFL.
