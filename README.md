# UEC 2027 备考系统

给自己用的手机备考网页：课程地图（116 章，标记“已学”）、今日任务（按学习计划 + 第 1/3/7/14/30 天间隔回忆，点“完成”即可，没有评分）、错题本（错因分类，连续重做对 2 次算掌握）、考试日历。

## 部署到 GitHub Pages
1. 新建仓库，把本目录所有文件放到根目录并推送。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 几分钟后用手机打开 `https://<用户名>.github.io/<仓库名>/`，可“添加到主屏幕”。

本地预览：`python3 -m http.server`，再开 `http://localhost:8000`。

## 数据与进度
- `data/curriculum.json`：课本章节对照表，来自 `curriculum_map.csv`。`index.html` 里内嵌了同一份数据，改章节时两处一起改。
- 进度存在浏览器 localStorage，只在同一台设备保留。换设备前在“考试日历”页底部导出，在新设备导入。
- 考试日期（期末、预试、毕业考、2027 统考）都待填，不要当作官方日期。

## 内容规则
讲解、例题、模拟题一律原创并标“原创，非官方”，不冒充真题或董总评分标准；不放课本全文；官方纲要为 2026 年版，2027 版出来后要重新核对。

## 讲解内容（lessons/）
每章一个文件，如 `lessons/phys03.js`，写入 `LESSONS["物理3"]`（键 = 科目+章号，数学的科目名是“数学”）。新增后在 `index.html` 里加一行 `<script src="lessons/xxx.js"></script>`。
字段：`syl`（纲要条目）、`status`、`sections`（小节，与课本目录一一对应：id、标题、纲要号、正文、`figs` 插图 `[[路径,图注],…]`、公式、English 术语、易错/易混/记忆提醒）、`method`（考试格式、解题步骤、常见题型、评分点）、`ex`（例题）、`pr`（基础→困难练习）、`ext`（统考风格的延伸变式题：type、mk 分值、pt 变式点、q、steps、ans、trap），`vid`（视频搜索入口，待核）。
地图里的“必答区/选答区”标记按 2026 年版纲要的试卷结构推断，分题范围待核。

## 插图
物理等需要精确的图（s–t、v–t、受力图）由脚本生成 SVG，放在 `assets/fig/`，数值准确；概念性插画再交给 GPT image 生成。

## 考试格式的依据
各科试卷题型与题数以**老师发的学校资料 PDF** 为准（与官方纲要一致处不再注明）；官方纲要里有而老师资料没写的（如作答时间），笔记里会注明“官方纲要”。

## 题目层次
每章三层：基础题（`ex`、`pr` 里的基础）→ 进阶题（`pr`）→ **考试延伸变式题**（`ext`，每章 5 题，多步、带陷阱、含数据或图表分析）。题全部原创，不是历届真题；拿到老师的历届试卷后，可按其风格再调整。

## 版面
手机（宽度 < 900px）：单列，底部 4 个页签，图片占满宽度。电脑（≥ 900px）：左侧固定导航栏 220px，内容区最宽 1000px；课程地图和今日任务双列；讲解页左侧是“本章目录”，点击跳到对应小节。
